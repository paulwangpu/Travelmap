# 建康南界、南唐宫禁及明外郭补充

2026-10-22；发布版本仍为 2.3.4；保留全部未提交修改，未提交、未发布。

## 建康南界

此前研究包络采用现代街巷大致四至，而宣阳门点来自另一研究解释，造成门点在南边以外约72米。这是本轮纠正的问题。

不改变原始要素、原门点、宫城及考古遗迹。在 `displayCorrections` 中将整条南侧直边平移至已有宣阳门推定地段，使门点落在边上。没有为包住门点做局部鼓包。其余边仍是文献地段研究包络，不能因此宣称得到张学锋完整复原图或统一考古墙线；宣阳门仍不是出土门基。

## 南唐皇城／宫城

新增一个闭合淡填充面，以户部街一带北界、内桥南门地段、张府园护龙河发现地段及火瓦巷东界约束，参照原始OSM街巷解释大致范围。公开资料中“皇城”“宫城”“子城”常混用，尚无足够依据画成两重独立边界，故共用一面并明确说明。没有把羊皮巷工地当作已发现宫门，没有恢复先前撤下的旧规划面。

## 明外郭

依据南京市志办公布的卫星背景总览图，采用清凉门、神策门、太平门、中山门及中华门城堡五个地段作近似仿射配准，手工核对并描绘北、东、南侧主体走向、西南可见段、石城关—江东门短段和丁字墙。

原图是示意叠图，不是实测总平面。控制点拟合残差及独立地段差值仅用于检查配准一致性，不能表示墙界精度；原图外缘与仙鹤、沧波门既有更细地段可相差数百米，局部仍优先参考原始OSM道路及既有定位。已保存原图、像素描线、控制点、变换矩阵与检查结果。

丁字墙经原图放大复核：从通济门附近向南，经过双桥门地段，接近夹岗门一带的南侧外郭；没有误从上坊门斜接通济门。未把清代卡子门税卡当成明代城门。

新增15个图示门关参照，与原有姚坊、仙鹤、沧波三处一起覆盖总览图十八门关。全部注明图示地段，不生成未经考古确认的门基或瓮城面。外郭西侧原图断口及孤立关隘照原图保留，三组线均开放，不补成长江边的连续墙，更不生成伪闭合填充面。
