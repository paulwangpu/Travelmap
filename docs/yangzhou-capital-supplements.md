# 扬州古都与城址补充

补入10项范围或定位及1条南唐东都记录。

| 时期 | 已接入 | 对应限制 |
|---|---|---|
| 隋江都 | 蜀冈唐城现展示区定位参照 | 唐子城汇总轮廓不作为隋代宫界 |
| 唐 | 子城、罗城图件轮廓 | 子城南墙西段、罗城与子城是否相连仍有研究问题 |
| 杨吴、南唐 | 唐子城、罗城沿革参照 | 共用几何只绘制一次，不等于各朝逐段墙线相同 |
| 宋 | 宝祐城、夹城、大城图件；夹城现公园、南北门展示建筑；大城北门遗址点 | 高宗1128—1129年行在仅关联大城及北门，后建城圈不关联 |

论文图三为1975—2013年发掘位置汇总；2024论文对罗城北墙与子城的连接关系提出新问题，旧图轮廓仅作概略参考。所有图件面以虚线和半透明填充显示，沿平直边线内侧标注。OSM现代展示区保留原始几何，注明其性质。

五个城门参照的近似配准残差为11—73米，不是考古测绘精度，不代表远端墙线也有同等精度。扬州城市点更改到蜀冈展示区区域参照，原siteKey及各政权原始记录保留。
