# 地质显示模式（当前实现）

上次客户端多尺度拼接导致显著变慢，已从自动模式撤回。自动模式恢复Macrostrat carto现成PNG瓦片，自动模式的z4概略图作为空白处背景；不下载maps多级矢量、不逐像素扫描图例。

显示模式现有自动选择、局部详图、区域地质图、洲际地质图、全球概略图。前三个单尺度模式局部/区域从maps编译图的实际地质面按官方来源元数据large/medium过滤，失败时尝试carto同尺度地质面；洲际从已核实含small地质面的maps z5瓦片过滤，只下载当前级别的瓦片；区域最高z8、洲际最高z5后放大同一图面，局部最高z14。地图、位置查询与图例使用同一过滤规则。无该尺度地质面时显示空白，查询记录不能冒充已显示地图。

独立large/medium/small瓦片服务已停用，因此单尺度视图为现有carto数据的过滤视图，并非新增完整地图数据库。服务会按缩放筛选地质面，低缩放未返回的精细地质面不会凭空生成。官方说明：https://tiles.macrostrat.org/ 。

四尺度详情tab保留。缓存travel-map-v827，未发布Git版本。

美国验证地点：犹他州38.5945, -109.4324。局部source30 Wingate Sandstone、区域source133 Glen Canyon Group。单尺度主记录只选绘制顺序最上层地质面，避免分片重复。原先过滤carto会丢失被服务端优先级排除的同尺度地图，因此局部/区域改用单级maps（不恢复多级拼接）。maps z6在现场测试中连接中断或返回不可解码响应，美国现场确认maps z5对应source7洲际图，洲际模式改为z5。全球模式单独使用carto z2，对应source154全球图，避免z4已经选中洲际图造成尺度错配。

Louisville核查：38.2527, -85.7585。maps z10/12/14均含source22/map1903200局部地质面，点查询为Glacial outwash (Wisconsinan)。现场本地主页面加载v795/geology-auto v8，放大后图面及图例恢复，排除旧脚本缓存；不是当地缺少地质面。改为选择局部模式且zoom<10时自动放大至10，低缩放给明确提示。两种引擎市中心主记录一致。缓存v828。

覆盖交互（v829）：去除用户界面的数字缩放级别及选模式自动放大；用户点击“放大查看”才调整视图。覆盖状态区分已发现、低缩放未核实、已读取数据未发现、查询失败。可选虚线只描绘视野内已读取的局部地质面边界，不是图幅外框；尚无完整图幅边界，明确标记完整覆盖范围未核实。关闭边界时不额外下载地质瓦片，仅复用图例记录和来源元数据。移动后立即清理旧边界与状态，避免过时覆盖提示。
