# 开封历史多边形配准复核

宋东京里城与宫城的旧四点透视变换会引入剪切与局部尺度变化，本次改为平面米制坐标中的统一尺度、旋转和平移。保留每个原图描绘点、凹凸曲折、长宽比例及原始角度，不将不规则城界强行矩形化。

四处关联点为大梁门、曹门、安远门、大南门现状OSM位置。里城匹配残差约10—17米，宫城约13—38米；这是图件与现状参照的拟合残差，不等于考古测绘精度。原文献不同墙段有不同确认程度，里城保留原有虚线、宫城保留原描边样式，并继续注明图件参照性质。

外城此前已用原图1公里比例尺配准，仅旋转与平移；本次复核后保留原轮廓。魏大梁研究框的既有等比例修正也保留。明清开封城界来自独立CCWAD资料，原图存在真实的不规则城墙走向，不因视觉“不正”强改为方框。

原图作者误署为钱国祥，核对原PDF标题后更正为孟凡人。仅更正本篇开封图件署名，不改变其他钱国祥研究资料。
