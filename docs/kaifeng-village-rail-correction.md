# 宋东京外城：村庄与陇海铁路复核

本次使用图三的8处村庄地望：东官庄、辛庄、铁牛、兴隆屯、文庄、蔡屯、豆腐营、杨正门。村庄控制点来自OSM地名点，可能不等于原图年代的旧村中心，按较低权重关联；不是考古测绘控制点。

陇海铁路仅选OSM标为“陇海线”、usage=main的主线，排除郑开城际线、徐兰高铁以及货运支线。原图8处铁路线位中，6处参与近线约束，另2处留出独立核对。两处留出偏差由原来约91、70米减至42、16米。铁塔继续独立核对，偏差约74米。

私访院的旧图村点与OSM现地名点相差约1公里，未证明两者对应，不用于拟合。大北岗只作留出核对，差异仍约350米。图三大南门位置不够明确，降低权重；该点残差约240米，不隐去。这些差异说明原图及现状地名参照存在不确定性，不能将范围描述为精确GIS测绘。

采用统一尺度、旋转和平移，保留全部37个原始轮廓顶点和墙线折弯，不使用透视、剪切或局部橡皮拉伸。拟合尺度约10.562米/像素，与原图1000米/94像素的比例尺相差不到1%。原论文文字注明外城方位约190度，倾斜不应全部抹去。外城改动，既有大梁框、宋里城、宋宫城与CCWAD明清城界保留。

此前临时开封预览页直接用Google瓦片，缺少中国区域坐标纠偏。本次核对预览使用与主地图相同的GcjRegion及BasemapAlignment，使WGS84叠加与Google底图一致；不更改原始OSM数据坐标。

拟合参数、旧/新几何、逐村来源、铁路原始几何、训练/留出标识及误差见同名JSON。
