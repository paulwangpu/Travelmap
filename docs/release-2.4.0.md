# Travel Map 2.4.0

2026-10-24。

- 主图以“都城”统一控制古都、城墙和陵墓，图例三个分类采用同级样式。“陵墓”标题复选框直接全选或取消全部朝代，并显示半选状态。
- 增加“历史”图层，提供西汉公元2年、唐742年、北宋1102年、清1820年研究区划，可选择上级分区或郡国／府州。
- 补充中文政区名称，结合CHGIS、Hartwell和史籍区分同音地名；修正繁简后缀重复。原图未注名的区域保留说明，不推定名称。
- 上级分区从原始边界先合并再简化，清理细小碎片和孔洞，自动闭合窄河道状空隙，保留海南、台湾及较大的湖泊。仅对概览几何作显示处理。
- 历史图例增加0–100%填色透明度，实时调整并保存设置；历史标签采用与古都一致的字体、12px字号和描边。
- 增加政区、人口密度、人口总数三种显示模式。人口密度采用各时期固定色阶，总人数采用面积与人口成比例的圆；地名移至气泡外侧，气泡在历史地名上方绘制。
- 人口详情提供原表人口、密度、统计面积及来源口径，区分人口记录、户数乘5换算、史家估算和邻区推算。无记录保留为空值；上级人口按所属府级汇总，密度使用有记录部分的原始统计面积，不使用填缝后的显示面积。
- 更新资源版本及离线缓存，支持MapLibre和Leaflet显示路径。

区划和人口使用Zheng & Wu（2026）的ResearchArea研究层，覆盖范围和统计口径随时期不同；覆盖区人口合计不等同完整全国人口。部分边区地名存在跨期情况，概览填缝与简化不代表实测或逐年精确疆界。

来源：[研究文献](https://www.nature.com/articles/s41597-026-07086-6)、[原始数据](https://doi.org/10.6084/m9.figshare.30518417)、[复旦CHGIS](https://yugong.fudan.edu.cn/CHGIS/sjxz.htm)、[Hartwell GIS](https://doi.org/10.7910/DVN/29302)。中文对照另附各条地名的史籍来源。

验证：226项回归检查、版本一致性、脚本语法及Git差异检查；实际浏览器核对时期和层级切换、陵墓全选、中文地名、人口密度及比例圆、悬停点击、透明度与模式持久化、移动端布局。研究下载、临时文件、截图和私人导出不加入发布。
