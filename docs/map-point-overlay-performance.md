# 打卡与世界遗产重复显示优化

首次显示仍涉及目录加载、解析和图层绘制。此前重复开关会重建点位，并且世界遗产的每个点位都重新计算古城标记及打卡状态。

本轮修改：同一次点位渲染共享古城状态；古城名称与世界遗产别名使用索引查询；最多缓存8种点位显示组合。仅切换“我的打卡”不再清除数据和统计缓存，实际打卡、名称、语言或目录变更仍使对应结果更新。

本地无头 Edge 测量记录保存在 output/point-overlay-performance/before.json 和 after.json。计时范围是开关处理及紧随其后的微任务，不是首次网络下载或全部地图绘制时间。

| 操作 | 优化前 | 优化后重复显示 |
| --- | ---: | ---: |
| 我的打卡重新开启 | 346—436 ms | 14—15 ms |
| 世界遗产重新开启 | 378—515 ms | 12—14 ms |

复测重复显示未重新生成点位，也未重新上传大型遗迹图层。现有完整回归通过；新增测试验证1200项遗产共用一次古城状态计算、缓存复用、真实数据变更失效及缓存数量上限。语法和 git diff --check 通过。未提交、未发布，发布版本保持2.3.1。
