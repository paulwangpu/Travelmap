# 洛阳复原图整体校准复核

2026-10-21。保留当前所有成果，不提交、不发布，发布版本仍为2.3.4。

**本轮两点门址旋转方案已被后续[城墙方向与边界约束复核](luoyang-wall-constrained-calibration.md)替代。** 本文件和JSON保留上一轮尝试及其问题，不代表当前显示配准。

## 本轮变化

- 宫区16项参考几何统一使用[钱国祥《隋东都宫皇城的空间格局复原研究》图一](https://sites.lynu.edu.cn/hlwh/info/1023/1576.htm)，不再把三套图件的边线混接。
- 大内南墙采用突出于东西隔城的形制；宫城核心区与皇城共用阶梯状边线。圆璧城、曜仪城、玄武城、东西隔城与夹城保持连续。
- 东城与含嘉仓城共用整段南北分界。含嘉仓北侧按研究图斜线描绘，不凭现代道路补画。
- 109坊、3市及一组古洛水两岸，保留原考古报告复原影像的描绘，微调该图的整体配准；不将北部宫区的示意比例强套到全城。
- 13条宫区旧配准参考线仍完整保存在数据中，停止与新参考面重复叠绘。外郭城原开放参考线继续显示，不补出缺失的西墙。
- 共更新129项参考几何；其余882项要素完全不变。门址、明堂、天堂等实际标绘、原始开放线、古都根点、世界遗产和打卡身份保留。九洲池10处陆洲孔洞、两岸开放河线保留。

## 定位依据与限制

宫区以应天门保护展示建筑轴线附近、玄武门现有遗址标绘范围中心作两点位置参照，使用局部米制相似变换。玄武门本轮取整个标绘包络中心，不再将其某个外缘顶点当作门址中心。全城图以定鼎门UNESCO组件参照坐标和应天门位置参照校正原配准。

**上述位置参照不是考古实测控制点。** 两点相似变换的控制点重合由算法保证，不能作为独立精度验证。玄武门考古确认了位置及唐宋时期的迁移变化，参见[新华社转引中国社科院考古所工作队的发掘说明](https://www.xinhuanet.com/politics/2021-01/19/c_1126999404.htm)。该材料没有提供公开测量控制点，本轮不能据此声称精确测绘校准。

配准后的宫区东西宽约2138米，与研究记载的2100米接近；两个现状门址参照间距约942米，而论文中的隋代大内进深为1040米。此差别未消除，涉及图示比例、门址参照和历史分期，**不能将本图当作隋代或唐代某年的完整实测复原**。保留图示形状及透明说明，不把差值解释成考古误差，也不擅自推断门址迁移的精确距离。

里坊、九洲池和古洛水没有新增独立测量控制，仍属低分辨率复原参考；本轮不新增据坊名推定的寺院、官署、住宅点位。现代水系不变。

控制点、变更前129项完整快照、变更后散列、原始图上描绘点和882项保留校验见[校准审计JSON](luoyang-layout-calibration.json)。早期增补审计文件保持为当时快照；当前状态由本文件及同名测试验证。
