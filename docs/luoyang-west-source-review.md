# 西侧图示重新描线与上阳宫资料核对

2026-10-21。本轮纠正前版对西侧轮廓的处理，版本保持2.3.4，不提交、不发布。

后续更正：本页记述的像素提取曾保留锯齿与碎段，已进一步按原图直线和连续性整理。当前几何以[直线与连续性修正](luoyang-west-straight-lines.md)为准；本页的文献、考古资料及归属限制仍有效。

## 前版的错误

前版用17条手工概括线表示四条分隔线和13处“院落轮廓”，并称作“逐线对照”。这一表述不准确：部分转折被概括成矩形、部分双线和断口丢失，也没有获得每个块状轮廓的历史名称及功能依据。前版轮廓已撤换，不能把通过回归等同于忠于原图或考古准确。

## 本版几何

从用户提供图的灰色内部线、粉色外缘分别提取线条，进行保留连通关系的细化和0.8源图像素的简化，保留可辨双线、折角和识别断口，不自动补出不存在的闭合矩形。内部55段按北、中、南三组保存，外缘26段另作一组；仍使用既有四个标识，不新增开关、根点或打卡项。

显示改为较细、较淡的连续线，以便与原图核对；`inferredBoundary`仍为true，详情明确“原图参考，非实测”。连续线表示原图的符号，不表示发掘确认。灰线不直接命名为宫墙、道路、院落或殿基；重复标签不增加。提取中断也不等于已确认的历史城门缺口。

原始图的出版来源、编绘年代和地面定位精度仍未核清。0.8像素只描述图像简化，不是地面精度；与原图一致也不等于历史真实。配准沿用现有天街和南墙框架，不以这些图示线条反过来移动考古点。

研究原图、线条掩膜、源图叠加核对图在output/luoyang-north-water；修改前五项完整快照、逐段像素点、原图散列在[审计JSON](luoyang-west-source-review.json)。其余1050项要素逐项不变，包括桥、河道、全部112项坊市、考古/OSM墙线和门址。

## 有哪些资料说明西侧建筑

**上阳宫有明确的文献和局部园林考古资料，不能概括为“没有资料”。但这些资料尚不能给用户图西侧每个方框逐一命名。**

| 证据类型 | 可确认的信息 | 不能据此推定的内容 |
|---|---|---|
| 《河南志》上阳宫条及古图图说 | 提象门、星躔门、观风门、观风殿、浴日楼、七宝阁、化成／化城院、仙居殿等名称和部分相对次序；另有西上阳宫记载 | 用户图每个圆点、小框与这些名称的对应、现代经纬度、完整宫界 |
| 支建街一带园林发掘及研究 | 水池、廊房、水榭、石子路、假山等实际遗迹；清理的是局部园林 | 全宫布局、全部院落功能；研究中“可能为化成院或仙居殿”不能改成已确认 |
| 用户提供全城示意图 | 可辨的围合、双线、内部块状轮廓 | 每条灰线都是真实墙基、整片围合就是考古确认的上阳宫 |

门殿名和发掘内容已补入现有“上阳宫（地望参考）”详情，保持该点相对定位的限制，不把这些名字分配给未确认的小框。
