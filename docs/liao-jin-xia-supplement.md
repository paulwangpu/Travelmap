# 辽、金、西夏城址与遗存补充

本批新增11项，研究范围累计266项。沿用现有城墙范围开关、朝代颜色、闭合面填充与标签规则，无新增主开关。

| 地点 | 本次内容 | 资料性质 |
| --- | --- | --- |
| 金上京会宁府 | 南城、北城衔接参照面；8段原始城垣合为一个开放线集合；皇城所在遗址展示区；皇帝寨参照点 | 南北城沿原始矢量逐段保留顶点，缺口直线衔接为推定，显示虚线；原始残垣线不填充且不重复逐段放label。展示区不冒充考古实测皇城墙。 |
| 西夏兴庆府 | 承天寺现寺院范围、承天寺塔现建筑面、海宝塔现建筑面 | 承天寺塔1050年始建，1820年重建，名称及说明明确现存塔是清代重建；寺院现状用地不表示西夏寺界或城界。海宝塔始建年代不明，保留历史参照意义。 |
| 辽义州 | 奉国寺现寺院范围、现存辽代大雄殿 | 清代、现代构件不一并称为辽代建筑；现代安泰门不作为辽城门接入。军事镇城和寺院不新增为古都列表项。 |
| 黑水城 | 现存城垣范围 | 西夏军事城镇沿用址，现存外圈主要为元代扩筑。选择元时用元色和“元亦集乃路”名称；仅选宋辽金西夏时用该色并明确“现城垣为元代扩筑”。同一几何只画一次。西夏238米旧城精确分期边界未接入。 |

会宁府旧参照点（126.97,45.54）更正至金上京皇城遗址地点（126.9727109,45.4894965）；兴庆府旧点（106.2309,38.4872）更正至承天寺塔参照。地点ID保持不变，朝代记录同步更新，原坐标保留在locationReference。

西平府定位存在历史地理问题，省嵬城尚未取得可靠矢量，均未以现代城界或粗略矩形替代。本批也未使用OSM“兴庆老城”历史街区面作为西夏兴庆府城墙。
