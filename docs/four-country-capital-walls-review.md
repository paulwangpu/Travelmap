# 德国、法国、匈牙利、荷兰古都城墙核验

本轮审计32座既有城市，增量加入183项线／面几何，没有新增点位或古都根点。原有1928项几何经深度比较全部保留；世界遗产数据、古都身份、坐标及495条都城记录未改变。未提交、未发布，发布版本仍为2.3.1。

## 城郭范围与几何性质

慕尼黑加入第一道、第二道城郭及近世棱堡城防的三个闭合面，依据市政府《Die befestigte Stadt》图54配准，属于图示参考，非实测墙界。独立建筑锚点核对差值不能作为城界精度。

乌得勒支接入市政府1200、1550、1670三个分期的118项城墙、城门和堡垒复原几何，并从原始墙体合并结果的闭合内环提取三个城郭参考面，未补接缺口。官方复原与现存遗迹分别标注。1500_muur服务名称与“14世纪”标题冲突，57项暂不接入。

其余新增以原始OSM城墙段、城门和堡垒范围为主。开放墙段仍保持开放；闭合面填充；同城同分期墙段共用一个标签，原始几何未删。已排除凡尔赛园林围墙、柏林冷战墙和布达佩斯同名旅馆。海牙宫廷入口明确为庭院城门，不能作为环城城防。
