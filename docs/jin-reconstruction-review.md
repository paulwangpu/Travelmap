# 金中都研究图配准及考古控制点核验

2026-10-16；版本保持2.3.3；未提交、未发布。

## 当前结论

尚未完成按高楼村、万泉寺、凤凰嘴、南城墙水关和2024年端礼门发掘位置联合约束的城界校准。现有外郭、皇城、宫城和13处门址属于研究图配准参考，不能视为考古测绘复原。本次核验不移动几何，避免以村庄、公园或现代建筑中心冒充发掘坐标。

来源为刘未《辽金燕京城研究史——城市考古方法论的思考》（故宫博物院院刊2016年第2期）印刷页90/PDF第14页图十四所载徐苹芳2012复原方案。该图早于2019—2024年的新发掘。

## 五处考古依据与实际使用情况

| 依据 | 当前使用情况 | 尚缺内容 |
|---|---|---|
| 高楼村西城墙 | 未作为配准控制点，仅核对区域位置 | 墙体中心线、马面和护城河的可定位测绘图或坐标 |
| 万泉寺南城墙 | 未作为配准控制点，仅核对区域位置 | 各发掘段的位置、方向和坐标；不能以村名中心代替 |
| 凤凰嘴南城墙 | 未作为配准控制点；现代公园地块不等于遗迹轮廓 | 土丘中心线可靠定位及与万泉寺、高楼村的共同约束 |
| 南城墙水关 | 参与配准，但使用现代保护建筑的OSM几何中心 | 涵洞穿墙段及南墙中心线的实测位置 |
| 2024年端礼门 | 当前门点来自2012年图，不是新发掘定位 | 新发掘门道、两侧墙体和瓮城的可定位测绘图或坐标 |

官方资料确认遗迹和发掘事实；目前取得的资料尚不足以为五处建立统一坐标系下的测量控制点。长度、宽度等尺寸不能单独推导经纬度。

官方保护文件以万泉寺遗迹南侧与凤凰嘴遗迹中线为南墙中线，向凤凰嘴以西380米延伸，再连接高楼遗址中心确定西墙中线。不能直接以凤凰嘴或公园景观折角充当古城西南角；应用该规则前必须可靠定位三处实际遗迹。

## 数据保留和验证边界

本批保留17项：三重城郭研究复原面、太液池（鱼藻池）现状遗址地块一面，以及13处研究门址点；全局研究要素855项。16项推测复原不提供实物独立打卡，太液池地块保留独立身份。

“鱼藻池水面（研究图示）”已按用户要求移除，保留遗址地块不表示复原了历史池岸。原有838项与古都目录的保存核验见同名JSON报告。本次只修订核验文档，不更改地图几何或打卡记录。

旧埋藏区几何保留但不再作为城界显示。现代公园地块只是部分现状园地参照。

此前回归与浏览器检查验证加载、标签、开关、关联、打卡及数据保留，不证明考古位置准确。旧截图中的水面属于移除前状态。当前zoom11/12/13标签计数分别1/4/17。

尚待完成：五处考古锚点可靠定位及共同校准，新发掘墙体、城门实际轮廓，以及皇城、宫城与园池复原方案比对。不得宣称已完成依据新考古结果的城界复原。
