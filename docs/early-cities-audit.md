# 夏以前古城补充与既有皇陵关联

2026-10-17；版本2.3.3，不提交、不发布。

新增7个古城目录条目、4个都邑根点／4条记录、27项显示几何；总计508个根点、748条记录、425个目录条目、2782项几何。

良渚、陶寺、石峁及卡拉尔按有据的早期国家或区域政治中心收录都邑；城头山、埃利都、焚城按实际考古古城收录，不以存在建筑或传世王表直接认定具体国家都城。

## 皇陵与打卡

完整皇陵目录保持原样；复用early-liangzhu、early-taosi、early-shimao，不重建墓地条目、不改名、不移动坐标、不合并打卡。城址详情可打开既有皇陵详情，打开关联详情不等于打卡，也不会自动打开皇陵图层。三条墓地原有坐标都是区域参考点，不是已配准的墓地中心。

良渚和埃利都只关联原世界遗产ID，不将串联遗产整体并为一座城市；焚城和卡拉尔保留原世界遗产坐标、名称、ID及打卡身份。

## 已有多拉维拉

仅补充早期城市的显示时期：根点同时受“夏以前”和“夏商”筛选，详情列出两个阶段；所有原有构件几何与分期完全保持原样，不将后期城墙倒推到前3000年。精确改动及原目录快照保存在机器审计的permittedChanges和baselineRestores。
