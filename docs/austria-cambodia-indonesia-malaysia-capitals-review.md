# 奥地利、柬埔寨、印度尼西亚、马来西亚古都与城郭

本轮审计35处城市／王廷中心，新增29个古都根点和34条都城记录；新增76项实际线／面几何，没有新增泛用点位。另将吴哥147项既有几何原样迁入全局，包含罗洛士旧都的三个既有寺庙组件。

原有2111项几何、原有291个古都根点与495条记录均经深度比较保留，世界遗产文件、坐标、标识和既有打卡身份未改变。未提交、未发布，公开版本仍为2.3.1。

## 城墙与围界

- 奥地利：接入四城合计61条原始墙体way，另有霍亨萨尔茨堡、格拉茨棱堡及城门、维也纳与因斯布鲁克霍夫堡建筑群。维也纳原棱堡位置的现状墙面含后期城坡挡墙，不称为完整原防御城墙。
- 柬埔寨：洛韦古城LiDAR研究标绘范围与护城河、金边王宫围墙和内部建筑、贡开寺庙圣区及水库、伊奢那补罗寺院围区。寺庙区不代替城市西侧城郭。吴哥城、王宫、城门、开放墙线与EFEO研究围界统一进入ClassicalSites；罗洛士早期都城分址。
- 印尼：梭罗原始闭合王城外墙及内廷、日惹现存开放城墙／城门／棱堡和内宫、万丹苏罗索万王宫城、松巴奥普堡遗址和墙段、巨港库托贝萨克开放墙段、托卢科及托雷堡。殖民堡垒与苏丹宫城分别注明。
- 马来西亚：吉打河口堡垒闭合现状围界、哥打巴鲁大议事宫围界及王宫建筑、神安池旧宫和旧国家王宫等。马六甲既有堡垒、王宫和细节原样保留；其共享遗产编号的乔治市根点未移动。

闭合面按实际对象填充；开放墙线未强行闭合。多面和孔洞保留，同名同分期墙段共用标签。新接入的梭罗王城、金边王宫等是原始OSM围界，洛韦是明确标注的研究城址范围，并不等同实测现存墙界。

## 分类和全局接入

因斯布鲁克、维也纳新城、北根、江沙按政府／宫廷或王室治所收录为普通古城；吴哥波雷标注扶南王都候选及政治中心、UNESCO预备名单身份。没有将其升级为确定的国家都城。普通古城沿用全局总开关；按最新统一规则，根点图标和名称同时受对应时代的legend筛选。

古都图标与名称使用全局5／11缩放规则；朝代legend同时控制图标与名称，城墙总开关和时期只控制城郭及内部细节。吴哥独立渲染入口和独立资源预缓存已停用，原始数据文件仍保留作核验依据。吴哥寺世界遗产锚点与吴哥城王都根点分址保留，未移动世界遗产点去代替大吴哥政治中心。

## 仍待核的完整城界

- 维也纳完整各期城郭和Linienwall
- 萨尔茨堡历期完整两岸城郭
- 伊奢那补罗西侧城市区完整城界（现有为寺院围墙）
- 吴哥波雷扶南时期分期城郭
- 乌栋山下王都与宫城
- 柔佛旧都两段王都和旧堡完整墙界
- 日惹外层Baluwarti缺失墙段及内外墙完整分期
- 特罗乌兰完整满者伯夷全城及宮城
- 亚齐、特尔纳特和蒂多雷各期宫城

本轮不宣称四国全部历史王都已经穷尽；其余政治中心候选见JSON审计清单，需按政治身份、年代和真实几何逐城核证。没有可靠矢量的条目保留历史记录及明确缺失说明，不以随意四边形或点位填数。
