# 洛北里坊与桥河冲突修复、西侧图示细部

2026-10-21。本地增量修正；版本仍为2.3.4，不提交、不发布。

后续更正：下文记录的17条西侧手工概括线已撤换。“逐线对照”不能作为该版的准确性结论。当前西侧图形及历史资料说明以[重新描线核对](luoyang-west-source-review.md)为准；本版桥、河道和里坊冲突修复保持有效。

## 问题与修正

上版只调整了洛南83项坊市，洛北29项仍沿用较早的报告图配准，而洛水和六条桥线已换用用户图示。两套参考不一致，使新中桥穿入承福坊、会通桥穿入铜驼坊。上版没有执行桥线与坊面相交检查，视觉核验也漏掉了这两处。

本版以当前图示北岸为洛北坊区的南侧参照，固定外郭北墙参考线，对29项采用共享的单调南北格网调整，保留原坊名、标识、分区次序和南北方向。北岸与坊界留45米图示间隔，仅用于清楚区分图层，**不是考古确认的道路宽度、堤岸距离或历史退界**。不移动桥梁来迁就坊界，不把实际遗址或原始OSM构件推向新图。

六条桥线、古洛水两岸、洲岛孔洞、全部洛南83项和宫区参考仍原样保留。所有112项坊市均检查桥线相交和历史水面相交，不能只检查标签是否遮挡。

新中桥、旧中桥、会通桥名称与具体桥位的对应关系仍沿用既有待核说明；修复图层冲突不意味着确认了分期和桥位精度。

## 西侧细部

对照用户提供的同一张示意图，新增三组实际多线要素：

- 内部四条较长分隔线。
- 北部七处可辨块状轮廓。
- 南部六处可辨块状轮廓。

共17条线，按三组组织，减少重复标签；可点击查看来源说明。原图未标名，分隔线可能表达道路或分区，小块也不一定全是宫殿院落，所以不附会殿名、门名和建筑功能。线条只作图示参考，不填成实测建筑或确认宫城，不新增条间、坊间道路标签。上阳宫完整宫界及西侧围合归属仍待核。

来源为用户图片 `codex-clipboard-041c1fc6-cd65-4425-9a09-1ec88ccabc9c.png`，研究副本在 `output/luoyang-north-water/user-river-reference.png`。沿用前版以天街方向及南墙方向作参照的配准。图上点和完整修改前快照见[审计JSON](luoyang-river-ward-clearance.json)。此图原始编绘来源和测量精度未核实，不因细节增加而提升其证据等级。
