# 洛阳城墙方向与边界约束复核

2026-10-21。本次替代上一轮两个门址参照的旋转配准；不提交、不发布，版本保持2.3.4。

## 为什么还会有角度差

原始考古图开放参考线、里坊影像和宫区示意图分别配准。上一轮用定鼎门/应天门及应天门/玄武门的点位置旋转图件，却没有把外郭南墙、东墙整段作为硬约束。点看似接近，整段边界仍会偏转。用玄武门标绘包络中心也不能保证城墙方位。

现有外郭参考南墙在局部米制坐标中的方向约7.14°，定鼎门片区现状OSM长墙段的方向约5.86°，相差约1.29°。这是真实的数据配准差别，不能以缩放显示或不同历史时期直接解释。

## 本次处理

1. 保留全部原始要素。选取OSM `1207094398`、`1207094399` 两条长墙线的13个顶点核对现状南墙方向。整体参考框架只旋转和平移，不移动任何OSM遗址或保护展示构件。
2. 另外四段OSM短墙线 `387176287—387176290` 不参加拟合，留作图形一致性核对；它们与校正参考南墙的最大垂距约5米。**这仅说明同一OSM数据中的墙段较一致，不是独立考古精度验证。**
3. 原始开放外郭线在数据中原样保留；页面使用它在同一校正框架中的显示副本，仍是北、东、南三边开放线，不补西墙。旧的45米辅助对照值不再放进当前显示详情。
4. 复原影像的四个对应城角采用四点投影配准，严格落到这组显示参考线；整条南边和东边共线，而不只是端点接近。定鼎门、应天门保留为检查项，不再加入会转动边界的最小二乘拟合。
5. 宫区用考古报告图中的对应墙线作分区匹配，再采用同一南墙方向校正框架，撤销应天门—玄武门的两点旋转。保留大内南墙突出形、分区共边、水面陆洲孔洞和古洛水两岸开放线。
6. 修正早期坊区提取表把各排水平套入斜向复原影像的问题：北、南排按图中城界归一，东侧保留原图内侧留白。112个坊市全部保留，北、东、南侧不再越墙。此操作修正图形提取，不构成逐坊考古边界核定。
7. 再用[天街址原始标绘](https://www.openstreetmap.org/way/1417204157)两端短边中点连线核对南北向：其局部米制角度约96.233°，原参考框架约95.865°，差约0.368°；较长[天街标绘](https://www.openstreetmap.org/way/1203892879)未参与方向选定，检查约96.231°。固定已核对的南墙方向，仅调整南北向基向量，不再将全图作刚性旋转。两个天街原始构件及全部882项原始要素仍原样保留。此为现状地图轴线参照，不能断言所有历史街道、城墙及各分期严格平行或正交。
8. 112个坊市的纵向列线不再经过会带入透视倾斜的四点投影，改用南墙与天街构成的斜坐标格网，纵向列线与天街一致。天街源图位置列同时与现状天街中线对照；顶部行仍受北城界约束，南、东侧继续不越墙。此项替代前述里坊投影的列线处理，四点城角约束保留用于外郭与古洛水参考。它是图示格网校正，不能据此断言各坊实测墙线皆严格平行。

共更新129项复原参考几何，其余882项原始要素和所有根点、世界遗产、打卡身份不变。显示副本不增加图层或打卡项目，继续使用全局城墙控制。

## 依据与限制

- [国博公开2014年考古报告实测图](https://www.chnmuseum.cn/fw/jyhdyy/202604/t20260416_279032.shtml)：保留原始图上开放描绘；原先地理配准不是测量控制网。
- [故宫院刊转引的考古报告复原图](https://www.dpm.org.cn/Uploads/File/2021/01/20/u6007f09329708.pdf#page=12)：用于里坊和古河道。
- [钱国祥宫皇城复原研究](https://sites.lynu.edu.cn/hlwh/info/1023/1576.htm)：用于辨认分区及对应墙线，图示比例不能当成实际分期测绘。
- [洛阳市政府文博规划](https://www.ly.gov.cn/2023/08-24/32967.html)：明确定鼎门及东西城墙有保护展示内容。因此OSM现状矢量适合核对定位和方向，但不得笼统称为考古发掘实测线。
- [洛阳市政府2025年天街保护展示工程说明](https://www.ly.gov.cn/2025/03-05/522097.html)：天街现状包含保护展示工程；现状OSM足迹不应直接称为考古发掘测量边界。

**本轮解决图件彼此角度不一致的问题，没有获得新的独立考古实测坐标。** 北、东墙的全长位置仍继承考古报告图，不能用定鼎门一处的现状墙段宣称全城都达到约5米精度。四城角来自同一图系，也不是四个独立地面控制点。完整分期墙界继续待核。
