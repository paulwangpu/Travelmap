# 辽五京补充核查

本次范围为辽五京，北京辽南京保留原资料。其余四京新增15项，均由城墙范围的“宋辽金西夏”控制；无新增主开关。研究范围总数由240增至255。

| 城市 | 本次新增 | 数据性质与限制 |
| --- | --- | --- |
| 上京临潢府 | 皇城、西山坡佛寺、乾德门、北塔，共4项 | 皇城为OSM现状范围，按卫星影像和官方双城布局核对；南部汉城及宫城考古实测边界未接入。佛寺、门址、塔为地点参照，有可见点标记。 |
| 中京大定府 | 大明塔展示区、大明塔建筑、小塔、半截塔，共4项 | 展示区不作为外城；塔有建筑面或点。原点119.33、41.6更正至大明塔119.1554531375、41.5697196125，约偏东15公里。siteKey/currentKey未改。 |
| 东京辽阳府 | 白塔现存建筑，共1项 | 辽阳白塔可作遗存参照；不是全城范围。后金东京城在太子河另一侧，不替代辽代东京。省文物资料涉及塔年代判断，保留辽、金异说说明。 |
| 西京大同府 | 华严寺大雄宝殿、薄伽教藏殿；善化寺天王殿、三圣殿、大雄宝殿、普贤阁，共6项 | 保留原2项现寺院范围，增加可核对的辽金建筑面；不接入现代华严宝塔、复建构件，也不把明清大同城墙当成辽代城界。 |

所有新增几何保留OSM原坐标和顶点，不将示意图强行配准为方框。公开影像核查采用Esri World Imagery（WGS84），OSM原始下载文件及考古图件留在本地output研究目录，不进入应用数据包。
