# Travel Map 2.3.2

本版汇总2.3.1之后的古都、城郭、历史遗址及交互性能改进。

- 扩充欧洲、东南亚、日本、摩洛哥、尼泊尔、占婆及中国地方政权古都记录，补充城墙、宫城、城门、堡垒及主要建筑。区分历史都城、王室治所、行省中心和身份未确定的古城。
- 古都主目录由155个根点、309条记录扩充至320个根点、529条记录；另有西域目录补充。ClassicalSites由11处、359项几何增至187处、2334项几何。
- 统一全球古都、城墙及遗址的渲染入口和城郭数据源，整合吴哥、庞贝及北京、洛阳分期显示。保留唐长安里坊、奈良等规划参考、原始几何、孔洞和来源许可。
- 古都图标与名称一起遵循朝代legend；城墙及内部遗迹采用独立的范围和时期控制。完善悬停、中文／英文名称、世界遗产打卡合并及普通古城显示。
- 闭合范围填充，开放墙线不强行闭合；减少重复标签，优化规划街坊、道路文字及缩放级别显示。实测遗迹、现存／修复构件、历史复原与图示参考分别注明。
- 改善底图切换、交互响应、我的打卡与世界遗产重复显示；稳定的点位及全球城郭集合复用缓存，避免重复构建和上传。

完整回归、相关JavaScript语法及Git差异检查通过。浏览器核验截图和原始研究缓存留在本地output，不随本次发布提交。具体来源、逐城审计与仍待核的完整城界见docs中的核验报告；本版不宣称已穷尽所有古都或复原全部城郭。
