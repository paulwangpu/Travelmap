# 燕下都城址补充

新增10项，归入既有古都、城墙范围的“周”选项，保持既有颜色、填充和标签规则。

- 东城：沿考古平面图逐段标绘城圈，保留北垣凸出与转折。西南临河城界为图示衔接推定，采用虚线和半透明填充。
- 西城：标绘图上能辨识的北墙、西墙及南垣残段。原图未给出完整南界，保留开放线，不画成矩形或强行闭合。
- 武阳台、老姆台：按公开WGS84影像中可辨认的现状台地边缘标绘；它们不是宫殿基槽、法定保护线或实测考古边界。老姆台在东城北墙外。
- 张公台、望景台、虚粮冢和九女台：图件位置参照，未取得独立可靠的测绘面，不以旋转矩形伪造范围。
- 东城横隔墙：单列晚期改造线。河北省文物局刊载研究将其解释为赵国占据武阳后的防御改造；不能视为燕国初建宫城南墙。
- 运粮河：单列古河道图示，保持蓝色，不作为城墙填充。

古都参照点由原来的115.53000、39.34600校核到武阳台基址参照115.5660224、39.2955999，避免落到偏北的易县县城区。原siteKey/currentKey保持不变，以兼容已有打卡。原始点位留存在locationReference.originalCoordinates。古都地点与309条原目录政权记录均保留；不把两处墓区的每一座封土指定给燕王。

## 配准及精度

图件来自孙冬虎供图的《全国重点文物保护单位》第1卷（文物出版社，2004）第250页。采用11处同名村庄的OSM参照点作统一尺度旋转拟合，避免把古图强制拉成正方形。拟合残差约8—145米，留一验证约9—206米；村庄标签代表概略位置，误差不能理解为城墙实测精度。郎井村、练台村的历史图示与现代标签对应误差较大，未作为拟合控制点。武阳台、老姆台现状轮廓独立从影像标绘，不随村庄拟合移动。

完整控制点、拟合参数、图件像素描线和现状台基像素线保存在[配准记录](yanxiadu-georeferencing.json)。台地边缘识别受影像年代、植被和整治影响，细节不应视为正式考古测绘。
