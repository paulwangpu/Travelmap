# 开封城门、城墙及考古节点增补

2026-10-22。版本保持2.3.5；本次未提交、未发布。新数据仅通过现有古都全局图层、城址范围及分期控制接入。

新增18个显示要素：11个现存／复建城门或交通门洞；2组城墙（保留17条开放线和6个原始闭合墙体面）；4个考古地段参照；1个州桥遗址现代展示建筑面。全部原始几何、分类、坐标来源和缺项见同名JSON。

## 门址与现状区分

- 明清门址及现状：大梁门、安远门、仁和门／曹门、丽景门／宋门、南薰门／大南门。现建筑或点位不能充作宋门基，明代控制下也明确是现状地段参照。
- 现代交通口：小西门、金耀门、河大东门、小南门、迎宾门、汴京门，归近现代。未因OSM `historic=city_gate` 自动回推为宋代门址。
- 原OSM大南门名为“朱雀门（大南门）”，显示更正为南薰门／大南门。宋里城朱雀门在其北，宋外城南薰门又是另一门，不复用坐标。宋朱雀门暂缺可复核地段坐标，不增加猜测点。
- 宋外城金耀门／固子门与现代金耀门、小西门与宋郑门、现曹门与宋外城新曹门均不合并。

## 考古新进展与复原线

- 顺天门／新郑门：采用既有2008图三西W1附近参照点及已保存的外城配准；与2012年起考古确认门址相区分，标为图件地段，非门基测量坐标。五代迎秋门与宋顺天门共用已确认的叠压城址，详情说明各期结构不同。
- 景龙门及里城北墙：2023—2024年考古确认，关联延福宫东墙信息。按体育路东、龙亭北路北的公开四至设地段参照点，存在约百米尺度不确定性；不声称点位是测量门道中心，不从尺寸描述拼造门台面。
- 黄河大街外城南墙：2023年工程考古，采用下穿陇海主线工程地段参照，非探方实测点。铁路仅为陇海主线，不混入其他铁路。
- 大梁门北马道：原址展示地段参照，不将展厅或文字尺寸转换成虚构发掘面。
- 州桥：采用原始OSM现代展馆轮廓作为展示建筑，不当作古桥、护岸或汴河边界。

2008年宋外城、里城、宫城图件早于上述新发掘。旧图几何保留，运行时加注“新考古墙线尚待配准”，宫城明确为参考面。新点仅达到公开地段精度，尚不足以拉伸、旋转或平移整套旧范围；待获得有控制点的发掘总平面后再局部校正。这里没有宣称已经按2024年考古结果精确复原全城。

## 保留与来源

原始研究总集、南京补充、古都根点与打卡存档均未改。17条开放墙线保持原分段与缺口，使用一个显示组减少重复标签；6个原本闭合的狭长墙体才填充。旧范围、孔洞和有效细节未被覆盖。

OSM批量接口两次失败后，沿用已有原始XML城防数据；对三处考古地段通过OSM原始地图接口重新核对道路。所有研究下载保留在output，不整体加入Git。

来源包括河南省文物考古研究院2017年顺天门简报、2024年开封考古保护综述，开封市文旅局2025年景龙门进展，开封历史地理信息平台的公开定位，开封党史方志网城墙与古马道介绍，以及孟凡人2008年故宫学刊图件。可打开的公众资料入口为 `sources/kaifeng.html`；各要素保留原始OSM链接或官方依据。
