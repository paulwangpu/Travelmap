# 元与北元城址补充

新增27项，采用OSM WGS84原始矢量，并以官方文物资料或考古研究核对名称、分期与资料性质。

- 上都：外城、皇城、宫城；华严寺、乾元寺、穆清阁、大安阁基址；13处城门参照点。不是世界遗产保护区范围。
- 元中都：宫城城垣参照。现代遗址公园用地不作为外城。外城、皇城尚待取得可靠几何。
- 应昌：外城、东西瓮城；删除候选中的重复外城面，仅接入一次。内城未据现代围栏推造。
- 和林：古城遗址标绘、大寺院遗址、石龟。OSM旧称窝阔台宫殿的区域依据德国考古院研究改称大寺院；额尔德尼昭为后世寺院，未作为元代宫城接入。

应昌、和林与元中都参照坐标已更正，保留持久化siteKey。张北近现代记录未跟随元代遗址记录迁移。

北元与元共用沿用城址几何，北元按既有明及同期筛选规则显示；不另造北元城界，不重复叠加。几何为公开遗址标绘，不是考古实测界址或法定保护范围。
