# Travel Map 2.3.5

2026-10-22。汇集 2.3.4 之后的地图、数据及界面修改。

- 增加导航栏隐藏／展开按钮，记住显示状态，适配桌面和移动端。
- 增补加拿大古都和历史政治中心，按身份区分都城、殖民行政中心及相关遗址，接入既有古都、城防和独立打卡系统。
- 完善洛阳都城、宫城、城门、里坊、道路、古洛水及桥梁；以遗址矢量和考古位置约束复原参考，保留原图、校准依据及不确定性说明。补充上阳宫区域细节，修正线条连续性、标签和资料入口。
- 复核南京明城墙原始 OSM 线面、宫城和皇城位置，补充各期城门、明外郭、总统府与太平天国相关遗迹，并复用全局分期控制。
- 六朝和南唐范围采用用户原图底图与 OSM 图块直接匹配，撤下旧建康方案；南唐北界另作北濠内侧与既有考古地段参照点约束。北门与北城墙考古地段合并展示，不将合并点称为已确认门基。
- 按用户最终要求撤下南京水道、城濠和环壕叠加、宫城南门参照点、长干东北墙基参照点、西街南朝道路，以及明外郭仙鹤门—沧波门道路参照线。原始研究数据归档，不恢复已撤下的显示；其他有效城墙、城门和范围保留。
- 范围地图标签使用名称，详情保留图示参考与非实测说明；同步资源查询版本及离线缓存。

古都目录 514 个根点、761 条记录；ClassicalSites 441 处、2885 项空间要素；南京补充原始研究数据 69 项，其中 16 项撤下显示。完整分期城界待核、现代现状及推测复原的区别继续保留，不以遗产保护区替代城界。

验证：206 项回归、相关脚本语法、版本一致性及 Git 差异检查；本地浏览器抽查南京分期范围、标签、合并点及控制状态并保存截图。研究下载、私人导出与核验截图不加入发布。
