# 全球地质图放大保留

自动模式后续升级为按来源尺度拼接真实地质面，当前实现详见 `geology-auto-mosaic.md`。以下保留全球概略覆盖方案的初始核查记录；全球概览模式继续适用。

自动模式：原有 Macrostrat carto 详细瓦片优先显示；zoom 4 概略瓦片在较高缩放时作为背景，保留其实际地质面覆盖。没有详细地质面时，点击主记录查询同一 zoom 4 编译；图例读取当前视野中的相同编译。无地质面的位置继续提示暂无数据，不补造海洋或国界外的地质面。

全球概览：两种地图引擎均将瓦片和查询限制为最高zoom 4，继续放大仅放大已有覆盖，不产生更详细数据。自动模式仍保留已有详细来源。

实现使用官方 HTTPS PNG/MVT 瓦片，按视野请求，不下载全球大文件；取消中国行政面限制，也不再预缓存中国裁剪资产。原来的中国资产及构建脚本保留为历史可复现材料，不再参与应用渲染。Macrostrat · CC BY 4.0，原始来源与尺度分类保留在详情中。

验证：真实zoom4瓦片覆盖东京、班加罗尔、内罗毕、布宜诺斯艾利斯；模拟高缩放空瓦片时检查主记录、颜色和图例一致，以及全球模式、缓存、取消和无数据状态。
