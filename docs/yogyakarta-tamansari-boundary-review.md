# 日惹塔曼萨里范围核对

- 王宫官方资料说明塔曼萨里为1758年开始营建、1765年完成主要建筑的王室园林；历史范围包括湖池、人工岛、宗教与防御设施，部分已成为居民区。
- 市旅游局将 Kampung Wisata Tamansari 解释为围绕水宫、支撑王宫与水宫旅游的现代社区。旅游村范围不作为历史园林、宫城或完整城郭边界。
- 接入 OSM way 549662633 的原始27顶点闭合面，命名“塔曼萨里水宫（现状游览范围）”，保留原始标签和来源，归入日惹现有全局城郭及内部遗迹图层，使用清时期控制。完整历史园林边界仍待核。
- 原有2334项几何逐项比较保持不变；仅新增1个面，日惹由7项增至8项。不新增根点、打卡身份或开关。
