# Travel Map 2.4.1

2026-10-29。

- 历史来源增加江山时序、TWHA与CHGIS本地接入，统一年份、步长、透明度和层级菜单；切换来源保留兼容设置。
- 江山时序补充政区背景缺口、完整层级悬停路径，隐藏周边疆界，清理显示孔洞与碎片；修复重复标签和年份切换后的标签延迟。
- 世界遗产图例加入全国重点文物保护单位，支持悬停、独立显示和打卡；修正遗产组成部分合并导致卡普阿等点位隐藏的问题。
- 增补东亚、中亚、玛雅、印度、缅甸、斯里兰卡、伊朗和非洲古都与王陵；增加资料链接、遗迹状态及考古范围说明。尼萨、库施、德干和锡吉里耶等分开记录古都、陵区、宫苑及定位参照。
- 完善大阪城、江户城的外部范围与主要遗迹，继续校准平城、秦咸阳宫等遗址，区分考古界、保护区、现存墙段和推定范围。
- 修正恭王府偏东的通用坐标，合并景区、博物馆和文保名称关联，兼容原有打卡并避免跨图层重复显示。
- 更新缓存和离线资源版本。公开发布不包含临时研究目录、私人导出或CHGIS／CITAS本地衍生几何；公开站点选择本地专用来源时给出明确提示。

来源与使用限制分别保留在各数据目录的NOTICE、来源页面和地点详情中。未核实的完整城界与墓主归属继续注明限制；遗址标绘不能替代实测边界或入口导航。

发布验证记录见本次提交说明；完整旧测试中仍含固定历史数量、整文件哈希及旧界面模拟断言，结果单独记录，不宣称全套通过。

验证：全量245项中197项通过、48项未通过，未通过项列于 [验证记录](release-2.4.1-validation.json)。古都覆盖、王陵校验、历史来源菜单、江山时序、TWHA、文保、恭王府及遗产组成部分等定向检查通过；本地浏览器核对新增地点、来源链接和恭王府合并。
