# 江山时序的时期与显示层级

此处的“上级／下级”是地图显示层次，不声称各朝只有两级行政制度。政权疆界另作背景；保留上游实际提供的两份图层，不因制度解释而禁用；重复郡级参考不改标为县界。

| 时期 | 上层显示 | 下层显示 | 数据限制 |
|---|---|---|---|
| 战国 | 诸侯国／封国 | 郡 | 国是政治实体，郡界仅有局部数据；原 region、prefecture 两层均含郡 |
| 秦 | 上层郡级参考（原图） | 下层郡级参考（原图） | 两层均保留，不将重复郡界称为县界 |
| 汉初至前107年 | 州部参考（原图） | 郡／国 | 上游参考层保留，但不声称当年已经设置州部 |
| 前106年至东汉中期 | 州部／刺史部（监察区） | 郡／国 | 州部不是一开始就为行政层级；下另有县 |
| 汉末、魏晋南北朝 | 州 | 郡／国 | 兼有侨州、侨郡；下另有县 |
| 隋 | 郡区等参考分区（原图） | 州／郡（原图） | 保留梁益诸郡等原图参考分区，不将州郡界改为县界 |
| 唐初至626年 | 州／府 | 县 | 尚未设十道；缺县界 |
| 唐627年起 | 道（监察／军政区） | 州／府／郡 | 道性质随时期变化；州郡称谓也有更改 |
| 五代十国 | 道／军政区 | 府／州／军 | 不同政权制度有别 |
| 宋辽金时期 | 路／道 | 府／州／军／监 | 按各政权区分；宋的路含监察、财赋等职能 |
| 元 | 中书省／行省／宣政院 | 路／府／州 | 实际层级可多于两级，路府州也非一律同级 |
| 明 | 两京直隶／布政使司 | 府／州／卫所等 | 民政、军政及土司体系并列出现在原图中 |
| 清 | 省／将军等辖区 | 府／直隶州／直隶厅 | 府以下另有州厅县，并非两级制 |
| 民国 | 省／地方 | 过渡府州厅、道或原图下级参考 | 废府、设道、废道有阶段差异；旧府界不改标为当年县界 |

前106、190、607、627等为菜单说明使用的分期界限，不表示原始几何在该年获得独立测绘更新。排除“非政区国土”占位要素，空缺继续由政权层提供背景及悬停回退。
