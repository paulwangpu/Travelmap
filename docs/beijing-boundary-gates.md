# 元明清城门沿现有城郭示意

2026-10-16；版本2.3.3；保留其他未提交修改，不提交、不发布。

按用户新要求，移除广安、广渠、左安、右安、东便、西便六门的桥区附近参考点，改为沿现有城郭多边形增加城门示意点。已有城楼、箭楼、角楼、值房及宫城门的原始实物几何保留。

共27个城郭门示意点。明清相同城门共用一点，依所选朝代着色显示；不额外复制清代点。宫城门沿用已有实物数据，本批没有把宫门、坛庙门和近代交通豁口混入城郭城门名单。

## 几何与名称

- 元大都采用现有beijing-yuan-outer-1368研究面；明清内、外城分别采用CCWAD北京sourceId 4、5。使用原始多边形分量，保留合并城界中会隐藏的内城南墙关系。
- 先按历史方位选择相应边，再按沿墙相对位置将点投影到该原边线。没有移动、细化或重画城界，没有将桥区中心转称实测门址。所有新点明确为“城界示意点”。
- 北肩两便门落在外城北边的东西露出部分；南面三门保持右安—永定—左安的东西顺序。元代十一门与明清内城九门分别对应各自城界，不能用一套位置代替两期南、北墙。
- 明代早期五个旧名在1439年前使用丽正、文明、顺承、齐化、平则；后用正阳、崇文、宣武、朝阳、阜成，改名细节存在文献讨论，本图采用1439年集中改名的简化分期。广安门在明代及1823年前清代显示广宁门，之后显示广安门；中英文一致。
- 外城建于1553年，本图随已有1564年起的外城数据记录显示；1537年选项不显示外城门点。
- 从zoom12显示门名，正阳、德胜、永定在已有实体标签可显示时由实体提供名称，避免示意点再重复贴字。所有示意点不提供独立实物打卡；已有实体打卡保留。

本轮移除6项、增加27项，保留其他855项不变，全局研究要素882项。几何来源哈希、原边线索引、插值比例和每点坐标见同名JSON核验记录。
