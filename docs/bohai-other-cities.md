# 渤海其他京城城墙

新增5项，均使用隋唐颜色与开关：

- 中京显德府（和龙西古城）：内城采用OSM原始轮廓，约190×310米；外城根据公开的630×730米及内外北墙70米间隔推定，中轴对称为假设，显示虚线，不能称实测边界。卫星有云遮，未据此宣称全城影像核验。
- 东京龙原府（珲春八连城）：外城采用OSM原始轮廓，与卫星边缘对照；内城按可辨认遗存边缘标绘，约218×318米，与吉林地方志描述相符；内城南门另作点位参照。不加入缺乏证据的更大外郭城。

和龙、珲春古都点由现代城市参照移到渤海内城，siteKey保持，朝代记录与几何对应分别核对。

西京鸭绿府、南京南海府青海土城，以及敦化敖东城尚缺本次可核对的城墙几何，未用现代城区或矩形猜测替代。逐项来源与影像信息见[bohai-other-cities.json](bohai-other-cities.json)。
