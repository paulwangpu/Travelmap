# 吴都（姑苏／阖闾城）候选范围

阖闾城位置存在争议。

- 木渎—胥口：重点显示考古城址地望范围，资料面积24.79 km²（约24.8）；概括面25.91 km²。四至连接为制图示意，非逐边墙基测量。
- 今苏州古城：复用原BIAM轮廓的空心虚线候选框，不声称为春秋城墙。
- 两处均归周代范围控制，均标争议；宋元、明清及原有城门几何保持。
