# 中东14个国家和地区古都与城防审计

核对日期：2026-10-17。版本保持2.3.3；本轮不提交、不发布。

共审计148个候选。新增99个古都根点、112条都城记录、120个目录条目、169项显示几何。总量为504根点／744记录／418目录／2755几何。

原始287项研究几何中，同城同阶段墙段合并为显示组，保留原始分段及来源；未强行补接开放墙线。没有可用内部几何的已核古都保留根点，并明确列出缺失项。普通古城没有可用几何者仅保留审计记录。

## 完整性与范围性质

原有405个根点、632条记录、298个目录条目及2586项几何按完整JSON深度哈希保持不变；世界遗产完整JSON保持不变。马里和耶路撒冷复用原有记录及几何，本轮不更改地域表达。

尼科西亚威尼斯城墙、菲鲁扎巴德古尔城：接入原始闭合矢量支持的城郭参考面，非考古测绘成果。其他城墙仅表示现存／标绘段或墙体面，不将遗址园区、卫城、王宫院落或遗产保护区当作完整城郭。

阿布扎比胡森宫堡原始关系存在拓扑问题；仅对新展示几何作make_valid处理，完整原始成员、孔洞和几何保留供追溯。所有新增展示几何通过拓扑有效性检查。

## 分类重点

- 布赛拉按发掘报告中的行政宗教中心表达；锡尔瓦赫按可能的军事中心表达，不自动提升为国家都城。
- 祖巴拉、弗赖哈、胡韦拉按贸易城镇／驻地审计，多哈独立收录；科威特城门建筑不补连为完整旧城墙。
- 旧、新坎大哈；旧、新帕福斯；朱尔詹古城和现代戈尔甘分别处理。新帕福斯的行省行政身份不等于独立王国都城。
- 伊朗的礼仪中心、季节性王廷和地方王朝中心在身份及年代中分别说明；古勒斯坦宫、波斯花园等独立遗产不并入整座城市打卡。
- 具体城址或直接政治身份不足的候选保持待核，不生成确定古都根点。
