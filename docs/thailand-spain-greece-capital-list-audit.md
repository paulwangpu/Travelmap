# 泰国、西班牙、希腊古都名单审计

结论：现有名单明显不完整。既有13处古都身份可以保留，但其中7处的表述或分期已修正。下表原确认的32处遗漏现已增量补录；城墙和遗迹完成状态见[实施清单](confirmed-three-country-capital-additions.json)。城墙、宫殿、世界遗产和打卡资料保持原样。

“待核”是尚未证实的候选，不是认定其为古都。本表不穷尽所有城邦和泰法。
