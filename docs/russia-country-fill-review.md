# 俄罗斯低缩放国家高亮伪影修复

2026-10-15。本地修复，发布版本仍为2.3.3；未提交、未推送。

在zoom 2与2.8复现俄罗斯欧洲部分内部的长斜线。分别检查原始国界、单独轮廓、单独填充和不同简化参数：原始几何没有该长边，轮廓单独显示时也没有此线；国家填充源的粗简化产生细长填充伪影。

`mapLibreSourceOptions()`将实际着色的国家多边形源（`visited-countries`、`admin-country-context`、`map-background-context`）简化误差降为0.1。国家点击命中源仍沿用0.9，省市等其他源的参数不变。保留原始国界、岛屿、孔洞、缩放上限、缓冲区、填充和轮廓样式；不删线、不改国界、不增图层。更新app查询版本与service worker缓存，版本号保持2.3.3。

浏览器将旧参数0.9、最终参数0.1与不简化参考0分别渲染到相同纯底画布；对参考填充内部（排除边缘3像素）逐像素比较。zoom 2／2.8／3／3.5／4／4.5／5／6／7共9例，最终参数的异常内部像素均为0；旧参数在zoom 2、2.8分别出现188、571个异常像素。实际应用国家高亮另核验zoom 2／2.8／3／4／5／7，并保存6张截图，无页面异常。

单次同一浏览器会话数据源就绪耗时：0.9为56ms，0.1为63ms，0为105ms。该数值仅为本地对照，不代表各设备性能保证。原始国家边界数据未修改；Leaflet路径不变。

复现、对照程序和截图位于`output/russia-outline/`：`matrix.cjs`、`matrix-results.json`、`qa.cjs`、`qa-results.json`、`after-2.8.png`。研究材料未纳入发布文件。
