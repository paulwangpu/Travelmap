# 胡志明市／西贡与嘉定城核证

本轮增量：1 个古都根点、2 条都城记录、3 项实际空间细节。既有根点、记录、目录项和全部几何与实施前 HEAD 深度比较完全一致。未提交、未发布；应用版本保持 2.3.2。

## 身份及定位

- 1790—1802：阮福映统一前的嘉定王廷／政治中心，中国对应朝代为清。第一郡官方沿革称1790年八卦城为 Gia Định kinh；1802年统一后国都在顺化。
- 1955—1975：西贡为越南共和国首都，中国对应朝代为近现代。
- 1698年地方治所与后来的行省行政身份不另列国家都城；不采用第一郡页面对1884年殖民行政地位的扩大表述。
- 一个根点，别名支持胡志明市、胡志明、西贡、嘉定、Saigon、Ho Chi Minh City、Gia Định。根点定位独立宫现代政治核心参照，默认地图时期为近现代；不表示1790年城郭中心。

## 城郭及几何

- 1790年龟城／八卦城与其后凤城分别说明。龟城毁弃及凤城营建年份在官方材料中有1835、1836、1837差异，采用1835—1837年前后的说明；凤城1859年被攻占后毁。
- 原始OSM没有核实到嘉定历史城墙线。relation 19260955 是现代行政区，不用于古城范围。
- 国家档案第二中心网页描述1859年图，但链接图片标题为1795年。图文年代对应待核；未配准、未绘制历史闭合城郭。现代道路包围范围也没有当作实测墙界。
- 原始 way 39598493：独立宫／统一宫现状闭合建筑轮廓。宫殿建于1962—1966年，非阮朝嘉定宫城。
- 原始 way 37911494：独立宫院区现状闭合围栏轮廓，作为现代院区参考面填充；非嘉定城墙。标签移至边线内侧避免与建筑和古都根点重叠。
- node 411926157：黎圣宗街与同起街路口参照。博物馆资料记载此处发现1790年红土石墙遗存；点不是墙体实测坐标，没有核实墙长、走向或当前开放状态。没有推画墙段或闭合面。

## 打卡图标

历史身份目录可独立加载，关闭古都图层时不依赖已显示的遗迹集合，也不下载遗迹GeoJSON。所有明确古都身份及旧目录中关联已核实古都根点的条目使用古都图标；明确普通古城的条目维持其分类。兼容29个无显式身份的旧目录古都；新增128个中英文世界遗产打卡别名，只采用既有目录中唯一关联的城市，多城市共享遗产不自动合并。既有目录项原样保留，别名存于目录顶层映射。MapLibre与Leaflet共用历史打卡主题。保留原打卡存档和内部遗迹独立打卡规则。
