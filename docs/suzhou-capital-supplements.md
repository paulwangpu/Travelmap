# 苏州古都、子城与城墙整理

保留吴国姑苏、元末张吴平江2条记录与原地点编号。城市点从古城西侧现代市区移至子城道路四至内的区域参照，非吴王宫或张士诚王宫精确位置。

新增12项标绘：

- 苏州子城：按地方志东公园路、西锦帆路、南十梓街、北干将路所述四至对应现代道路围合；仅宋元文献地望参考。
- 盘门城门及两翼城墙：现存多期遗构标绘，盘门城门1351年来源与原OSM标签保留；城墙复合面保留2个外环及2处孔洞。
- 胥门北侧2段现状城墙。
- 阊门与北侧修缮墙、金门近代城门。
- 相门北侧重建墙、娄门重建墙、齐门重建墙和相门重建城门定位。

已有明清苏州整体城界（CCWAD sourceId=1，13.6193平方千米）建立城市层面的对应，未另复制整城面。勾选元可看子城地望与盘门多期遗构参照；明清查看现状构件与已有整体城界，研究构件的明清颜色按所选年份一致。现状标绘并不表示所选年份时已经有现代重建建筑。

吴国都城具体城界存在研究争议，未用宋元子城道路四至或明清轮廓代替。2024年金城新村考古提供子城地区早期遗存依据，但不以该遗址论证为由随意补造吴王宫完整边界。
