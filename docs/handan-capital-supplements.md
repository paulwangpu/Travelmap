# 早期邯郸城址补充

古都列表保留“邯郸”及原始地点编号，原点从现代市区东北部移至赵王城西城内的区域参照。不是龙台建筑中心，也不是整个赵都的几何中心。

新增11项：赵王城西城、东城、北城三个闭合图示范围；东城南垣与北城西垣两段原图地上墙线；龙台及北城两处现状土基；西侧现代赵王城遗址公园范围；武灵丛台现存建筑；大北城赵苑地区参照点。

赵王城北城与大北城是不同城区。北、东城虚线主要依据原图“地下墙址”图例，不能把虚线理解为现存地上城墙。图示面为近似配准的城圈，填充不表示原图城门缺口已经补成墙体。现代公园不等于古代王城。丛台现状建筑也不是未经变化的战国平台原貌。

轮廓来源为郝良真《邯郸简史》47页宫城平面图，公开照片由我乃野云鹤上传、页面标注CC BY-SA 4.0。使用三个OSM现状土基中心的统一尺度旋转拟合，无剪切；匹配残差约9—20米，但不是测绘精度承诺。图片透视、古图概略程度和现状台基识别都有不确定性。像素描绘、参数、控制点及OSM原始几何保存在同名JSON。

大北城尚未接入完整轮廓：乔登云2017年论文指出南垣存在多期变化，战国大北城与汉大城不应假定完全重合；不按约数尺寸随意构造矩形。汉代赵国首府与中央政权都城也不能混为一类，未新增中央政权都城记录。

赵都邯郸终年由原表前222年更正为前228年；前222年不应作为邯郸都城终年。原政权年代字段仍保留来源表信息，区别政权延续与邯郸为都的时间。
