# 北京奥林匹克公园与美国奥林匹克国家公园身份修复

2026-10-15。版本保持2.3.3，本地修复，未提交、未发布；保留此前俄罗斯国家高亮修复。

原名称归一化同时移除“国家公园”和“公园”，使两处中文名称都变为“奥林匹克”。美国公园的别名因此被套到北京5A条目，导致北京条目共享美国身份，并在坐标查询中落到华盛顿州。

为目录内“奥林匹克公园”明确补充北京身份与中英文别名，名称键保留北京限定。美国既有`place:us-olympic`及其国家公园／世界遗产关联保持不变；北京使用`place:cn-beijing-olympic-park`。5A目录原名称、坐标原文和全部原始数据文件保持不变。

旧版明确保存为`china5a:place:us-olympic`或`china5a:奥林匹克`的5A勾选，转换为北京5A身份。只处理带中国5A前缀的旧标记，不迁移美国国家公园或世界遗产标记，不删除访问记录或修改原点位ID。已有清单点继续通过既有目录地理校正入口读取正确坐标。

验证：

- 北京中英文别名匹配北京身份与原坐标40.003031,116.38667；美国中英文别名保持美国身份与47.8021,-123.6044。
- 美国国家公园打卡关联美国世界遗产，不勾选北京5A；北京独立打卡可同时存在，取消北京不取消美国。
- 同时开启5A／国家公园和世界遗产时，美国位置的点位类别为`usNationalParks`，不出现北京5A条目。
- 遍历当前中国5A与美国NPS／美国世界遗产的中英文名称，未发现其他归一名称或规范身份冲突。
- 新增回归检查名称、双向匹配及旧标记迁移的隔离和幂等性；全量165项回归通过。浏览器以正常操作间隔核验打卡、中英文别名及两地显示，无页面异常。复现与截图位于`output/olympic-identity/`。
