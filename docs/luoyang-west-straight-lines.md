# 西侧线条直线化与连续性修正

2026-10-21。上一版的像素细化保留了锯齿和识别碎段，图示直线在地图上变成了许多细小折弯；这是处理方法的问题，不能用“忠于像素”解释为历史轮廓。

本版按原图的直线构图整理：

- 同一条直线上的小折点合并，保留建筑图式真正的转角。
- 同向碎段在原图有连续线条支持时接通；短转角间隙以两条直线的交点相接，保留平行双线，避免横接相邻双线。
- 粉色外缘按12条直边及其真实转角恢复为一条连续闭合折线。原图彩色圆点覆盖线条，不当作真实墙体缺口；这是恢复图示连续性，不是把考古开放墙线强行闭合。
- 原有四组要素标识保留；内部55个识别碎段整理为35条折线，外缘26段整理为一条，共146个顶点，取代上一版799个像素顶点。内部原图仍不能确认的断口不跨越大块空白强接。

只有四组西侧示意线改变，其余1051项要素逐项不变，包括桥河、112项坊市、原始考古/OSM城墙、门址及上阳宫文献说明。仍为细线图示参考，不作为实测墙界、宫殿地基或已确认的建筑命名。

直线转角、接线依据、修改前完整快照及源图坐标见[审计JSON](luoyang-west-straight-lines.json)。源图叠加核对图位于output/luoyang-north-water/west-straight-source-review.png，方法脚本和中间结果保存在同目录。此前关于上阳宫文献与局部园林发掘的说明见[资料核对](luoyang-west-source-review.md)。
