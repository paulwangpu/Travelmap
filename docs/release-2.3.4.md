# Travel Map 2.3.4

2026-10-18。本版汇集此前未发布的增补和修复；历史海岸线试作已撤销，不在本次发布内。

- 增补两河流域及中东14个国家和地区的古都、宫堡、城防和内部遗迹，保存逐城身份、年代、定位、原始几何与完整城界缺失项。复用既有世界遗产与马里、耶路撒冷等城址身份，不以遗址园区或保护范围冒充完整城墙。
- 增补良渚、陶寺、石峁、城头山、埃利都、焚城和卡拉尔等早期城址；区分已核政治中心与都城身份未定古城。传说控制显示为“传说／夏以前”，外国史前详情采用“夏以前”。既有相关墓地通过详情关联，保持独立打卡。
- 石峁同一 OSM 遗址面只显示一次，原始数据及独立皇城台范围保留；兼容两套旧遗迹打卡标识。反山墓地点位继续明确为古城组成区的区域参考，未移动到猜测位置。
- 完善北京辽南京、金中都及元明清城门的范围、遗迹和路口／护城河位置核对；保留考古依据和复原不确定性，去掉已撤回的宫苑、水面及无依据标绘。
- 根据帝陵资料继续补录皇陵及待考条目；无可靠位置的记录不上图，不以迁移文物或纪念地替代原墓址。
- 普通古城的点位和标签统一按所选中国对应朝代着色，保留普通古城形状；覆盖中英文、世界遗产合并点、打卡和取消打卡。古都、皇陵与独立遗迹的既有打卡身份保持分离。
- 增加 Gallup 安全指数和 Safeture 旅游风险底图；保留我的点亮在上层。Safeture 国家总体评级与区域评级合并显示，避免透明度叠加；提供摘要、点击区域边界及无数据状态，数据读取日期和来源分别记录。
- 修复俄罗斯低缩放国家填充的内部斜线伪影，更新矢量铁路源分组并复用已安装源及瓦片；改善底图切换、打卡及世界遗产重新显示的缓存与刷新。
- 修正美国 Olympic 相关分类识别，保持美国国家公园与中国5A分类分离。

当前主古都目录 **508个根点、748条记录**；ClassicalSites **425处、2782项空间要素**；皇陵目录 **513条**。中国对应朝代为全局显示控制，不替代当地政权及实际年代。所有图示参考、现代遗迹标绘和完整分期城界待核状态继续在详情及审计中保留。

完整187项回归、相关脚本语法、版本一致性及Git差异检查通过。本地浏览器已核验近期普通古城点／标签配色、时期切换、合并点、独立遗迹打卡和石峁去重；此前各批核验依据见对应docs报告。原始研究下载、核验截图和私人导出留在本地，不纳入发布。

本版创建新标签 `v2.3.4`，既有标签不移动。历史审计文档中的“版本保持2.3.3／未发布”等语句描述当时的研究状态，本版发布范围以此说明为准。
