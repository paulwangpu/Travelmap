# 杭州分期截图校准核对

2026-10-23。用户提供截图已保存：[参考图](../sources/hangzhou-user-phase-reference.png)。

## 结果

暂未取得可通过独立检查的地理配准。本轮没有修改地图城界。原作者、底图版本及坐标系未确认。

使用公开OSM路网制作了叠加检查。初步选取的体育场、广场、桥梁对应关系未能使整幅路网同时吻合，故撤销这些试配准；自动深色线匹配也出现错配。试验图只用于诊断，不代表有效控制点或城墙位置。

## 可以进一步约束的遗存

- **钱塘门遗址**：宋西城界考古约束；需要原发掘图门道位置，不能使用图中文字中心。[来源](https://z.hangzhou.com.cn/2022/syjy/content/content_8420727.html)
- **皇城**：凤凰山、馒头山、宋城路、万松岭四至与既有考古图；不以14.1平方公里保护工程范围代替宫墙。[来源](https://z.hangzhou.com.cn/2022/syjy/content/content_8420727.html)
- **望江路京城墙**：东侧墙段位置约束；与德寿宫宫墙分开。[来源](https://zjjcmspublic.oss-cn-hangzhou-zwynet-d01-a.internet.cloud.zj.gov.cn/jcms_files/jcms1/web2208/site/attach/0/d748bf7c2bb94087b29c84a6d08ba96c.pdf)
- **凤山水门**：元末1359年改筑的分期约束；不能代表整个元代。[来源](https://hznews.hangzhou.com.cn/wghz/content/2017-08/17/content_6629977.htm)

## 分期问题

- **隋唐**：大城与州县分立方案有分歧，不能仅凭截图确定完整城圈。[来源](https://hznews.hangzhou.com.cn/wghz/content/2021-12/07/content_8112285_0.htm)
- **吴越**：夹城、罗城需要分别考证，截图统一紫线不证明全圈为同一期墙体。[来源](https://www.hzzx.gov.cn/cshz/content/2024-08/30/content_8780738.htm)

## 下一步所需证据

可辨道路名的底图原图或同版地图；至少四处分布在北、中、南的确认路口，并留独立检验点。 钱塘门、皇城和发掘墙段用于独立检验，而非先依另一张复原图拟合后再宣称准确。现代河岸只用于底图配准，不当作古代岸线。


## 后续进展：2026年罗城研究图

找到杭州文史网2026年1月26日《子城、夹城、罗城——吴越杭城三步曲》所附完整罗城图。它与截图北部突出、南部山地围合关系相近，但未证明是截图原出处。已用四座山峰地望作等比近似定位，控制点残差72—316米；鼓楼独立地望检验约140米。新图以完整罗城示意参考接入，1985年东侧开放线保留数据并停止重复显示。所有其他时期、考古墙段和既有门址保持。此结果是研究复原方案，非实测墙界；截图本身仍未通过路网配准。
