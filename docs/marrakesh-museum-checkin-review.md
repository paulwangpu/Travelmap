# 马拉喀什博物馆打卡显示修正

## 原因

canonicalPlaceKey过去删除“博物馆／博物院”，因此“马拉喀什博物馆”被折叠为“马拉喀什”。历史主题判断将其识别为古都，古都图层开启时其通用打卡点被当作重复根点隐藏；旧数据中也没有博物馆建筑详情。

## 修改

- 名称规范化保留博物馆／博物院。只处理通用展示后缀，真实同一实体继续依明确别名关系识别，不按这些类别词将景点变成城市。
- 博物馆手工打卡不再仅因坐标相同而视为古都或世界遗产，不给父城清单增加状态，也不被父城取消操作移除。已经明确维护的同一对象别名关系保留。
- 新增“马拉喀什博物馆（迈内比府邸）”，采用OSM relation 4627685的原始建筑面；25顶点外环和5顶点院落孔洞均保留。标签放在原始面内而非院落孔洞中。仅补一处独立建筑，非皇城或全城范围，不新增古都根点、开关或打卡清单。
- 中文短标签为“马拉喀什博物馆”，主要建筑从zoom12起显示；描述区分19世纪末—20世纪初府邸和现状博物馆。原始建筑几何不因打卡改变。
- 为本馆建立明确的中英法名称访问别名，须名称完整匹配、位置在建筑参照点200米内且候选唯一，才关联手工点与真实建筑；不采用“马拉喀什”作为博物馆别名。远处同名点不匹配。
- 新建手工点保存稳定要素标识；旧手工点只在显示时识别，不自动改写存档。用户主动取消或重新打卡时，才按该真实要素精确处理其对应记录，保留其他城市及遗产状态。
- 通用点缓存加入已访问遗迹的实际可见状态，避免缩放或关闭城墙后复用错误隐藏结果。几何可见时将打卡状态展示在该要素上；zoom过小或关闭范围时仍保留“我的打卡”点。

## 依据

- [马拉喀什官方旅游局博物馆介绍](https://visitmarrakech.com/en/the-7-must-see-museums-of-marrakech-al-bahja/)：本馆设于迈内比府邸，位于本·优素福广场。
- [原始OSM建筑及孔洞](https://www.openstreetmap.org/relation/4627685)
