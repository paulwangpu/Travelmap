# 城址细节与名称整理

## 标签

唐长安坊名使用横排、居中，保留完整名称。取消导致中文逐字换行的零宽度设置，明确horizontal书写方向。扩充历史名称繁简转换：坊名、城门、宫苑、城垣和研究记录统一简体显示，原名仅在内部匹配来源记录时保留。

## 新增19项

- 渤海上京：第1—5号宫殿图示参照、宫城南北东西门及皇城南门。采用官方保护规划第67页宫城详图，以既有宫城四角配准；小构件不声称考古实测精度。保留原18项范围，不重复加入外郭城。
- 三星堆：南部局部遗址标绘、城墙遗存参照点。原OSM已明确注明实际遗址面积远大于该局部面，不能标为全城或精确祭祀坑。
- 石峁：东部遗址片区、皇城台片区。采用史前色，归入早期城址控制（现有夏商范围开关），不误标商代；现代考古遗址公园用地不作古城边界。
- 明中都：西南现存城垣、午门、西侧／东侧／中轴北段建筑遗存。未命名来源未注明的殿址。后世凤阳府城与明中都遗存分别显示。

三星堆完整城址、月亮湾与青关山；石峁内外城分层城垣；明中都完整三重城界仍需可靠分层几何，未以现代公园轮廓替代。

渤海及其他同址不同朝代记录只关联适用朝代的新增范围。新增轮廓均检查闭合与有限坐标，明中都及渤海细节进行了卫星叠图核对。坊名测试覆盖繁体输入、横排、中心位置及总开关。

逐项来源与渤海配准控制点见[archaeological-sites-refinement.json](archaeological-sites-refinement.json)。
