# 普通古城与古都使用统一时代筛选

普通古城根点的图标和名称现在与古都一样，受现有朝代legend控制。不改变历史身份，不因参与筛选就将普通城市升级为都城。普通古城继续使用原有普通古城样式。

此前`siteFeatures()`将非古都分类直接设为可见，`markerTheme()`也无条件返回普通古城图标，因此取消对应时期无法隐藏独立图标、标签或合并后的古城样式。现在两条路径共用`rootPeriods()`：非空`capitalPeriods`沿用原值，空数组则回退至已记录的`period`。目录中所有独立根点均有有效对应时期，不留缺省绕过规则。

MapLibre的根点名称与图标使用同一`iconVisible`过滤；Leaflet只为可见根点创建标记及其常驻标签。中英文、打卡状态、世界遗产别名共用筛选结果。普通古城的颜色、分类、坐标、几何和打卡身份保持原样。

城墙、图示范围与内部遗迹仍受城墙及墙体时期控制，不受根点朝代legend影响。世界遗产开关开启时，可以继续显示独立的世界遗产标记；仅显示我的打卡时，保留普通打卡红圈。这些标记不得继续套用已被legend关闭的古城图标和根点标签。底图自身地名由底图服务提供。

专项回归覆盖全部普通古城、空时期数组回退、单时期关闭与恢复、全部关闭、中英文、打卡前后、合并别名、MapLibre和Leaflet；检查根点筛选不改变城墙详情。浏览器通过实际点击legend复选框核验摩亨佐达罗、多拉维拉、庞贝和斯贴，并核验世界遗产及普通打卡回退。截图和结果保存在`output/ordinary-city-legend/`。
