# 北京城址分期

既有数据包括琉璃河西周燕都、蓟城、唐幽州、辽南京、金中都、元大都、明清北京。点位为区域参照，多个阶段共享点位不代表城界相同。

城墙范围分期控制：周为琉璃河保护与残墙参考；隋唐为唐幽州文献四至；宋辽金为金中都外郭、皇城、宫城研究复原及遗迹参照（埋藏区只留研究数据）；元为元末外郭复原及现代遗址公园说明；明清采用CCWAD年份范围。资料类别分别注明，不以现代公园或法定保护区替代古城墙。

2026-10-16复核：本批保留9项北京中心城区的金中都及明以前遗迹，原城址、阶段及根点不变。撤出配准证据不足的辽南京外郭与子城2个复原面，并按用户要求移出9项远郊遗迹，原始资料存output研究档案。金中都水关位于南城墙下，不应按较小的辽南京范围判断其是否在城内，也不移动其原始定位。金中都宫苑遗迹仅为局部；白塔、万宁桥及寺院场址区分原构、遗址与现状院区。详见[增量核验](../docs/beijing-preming-supplement.md)。

2026-10-16明清增量：追加24项城门、宫城、主要殿宇与墙体遗存，使用原始OSM闭合面／开放线并核对官方历史依据。正阳门城楼、箭楼分列；永定门标明2004年复建；紫禁城宫城不当作整个皇城。明清单选及年份控制均适用。详见[明清增补核验](../docs/beijing-mingqing-supplement.md)。

金中都重新核查：撤下现代埋藏区的范围显示，追加徐苹芳研究图配准的外郭、皇城、宫城和13门位置，并分别接入太液池现状地块与图示水面。均区别实物与研究复原，不称最新考古实测墙界。详见[金中都重建核验](../docs/jin-reconstruction-review.md)。
