# 洛阳城址分期

分期数据：东周、东汉、曹魏西晋、北魏、隋唐、明清。对应古都图例的独立阶段选择，可定位洛阳区域；各阶段同时遵循已有朝代开关。

目前接入的是可核实的遗址参考位置、分期说明及资料链接，以及 CCWAD 的明清重建城界。早期阶段**未绘制城界**：现有公开图尚未完成可靠配准，不能使用面积数字生成矩形、复制北魏范围至东汉、或把遗产保护范围当作古城范围。

- 东周王城：王城公园、涧河两岸的区域参照点，不是测量中心。东周成周另在汉魏故城区域显示参考点，以体现王城与成周的迁移；建都分段参考洛阳市官方历史文化规划。
- 东汉、曹魏西晋、北魏：使用 UNESCO 1442-002 给出的遗址位置 112°37′17″E、34°43′52″N。合并显示一个遗址标记避免叠加；共享参考点不表示不同阶段具有相同城界。
- 隋唐：使用 UNESCO 1442-004 定鼎门遗址位置 112°27′38″E、34°37′58″N。明确标注定鼎门，不解释为都城中心。
- 明清：范围取自 ancient-capital-walls.geojson；独立显示演变图层时，原有明清城墙图层排除洛阳，避免重复填色。

各条目 sources 保留出处。参考点与事实性分期说明由这些资料整理，未复制受版权保护的报告插图。
