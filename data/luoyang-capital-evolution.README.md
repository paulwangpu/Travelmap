# 洛阳城址分期

分期数据：东周、东汉、曹魏西晋、北魏、隋唐、明清。对应古都图例的独立阶段选择，可定位洛阳区域；各阶段同时遵循已有朝代开关。

目前接入的是可核实的遗址参考位置、分期说明及资料链接，以及 CCWAD 的明清重建城界。早期阶段**未完成实测分期城界**：现有公开图尚未完成可靠配准，不能使用面积数字生成矩形、复制北魏范围至东汉、或把遗产保护范围当作古城范围。

- 东周王城：王城公园、涧河两岸的区域参照点，不是测量中心。东周成周另在汉魏故城区域显示参考点，以体现王城与成周的迁移；建都分段参考洛阳市官方历史文化规划。
- 东汉、曹魏西晋、北魏：使用 UNESCO 1442-002 给出的遗址位置 112°37′17″E、34°43′52″N。合并显示一个遗址标记避免叠加；共享参考点不表示不同阶段具有相同城界。
- 隋唐：使用 UNESCO 1442-004 定鼎门遗址位置 112°27′38″E、34°37′58″N。明确标注定鼎门，不解释为都城中心。
- 明清：范围取自 ancient-capital-walls.geojson；独立显示演变图层时，原有明清城墙图层排除洛阳，避免重复填色。

各条目 sources 保留出处。参考点与事实性分期说明由这些资料整理，未复制受版权保护的报告插图。

## 2026-10-21 隋唐布局增补

在既有城垣开放参考线和实际遗迹基础上，增加宫城核心区、皇城、东城、含嘉仓城及大内五个布局参考面，并接入所用2014年考古报告复原图中的109坊及三市。属于指定图件的图示参考，不是独立测量成果或某年完整城界；原始开放墙线不覆盖、不删除。配准控制、辅助核对和未接入项目见 docs/luoyang-plan-expansion.json 与 .md。

### 北部隔城与历史水系

继续增补玄武城、曜仪城、圆璧城，东西隔城与夹城，陶光园核心，九洲池南北池和宫北引水渠；古洛水以两岸开放参考线显示。共12项，仍属隋代研究复原与综合年代的古河道图示，现代水系保留。来源、继承配准及约167米的门址辅助对照差见 docs/luoyang-north-water.md 与 .json。

### 整体配准与接边复核

其后对129项参考几何统一复核：宫区改用同一研究图及门址位置参照，大内与皇城共用突出形边线，东城与含嘉仓共边；里坊和古洛水仅校正原图配准。13条旧宫区配准线完整留存但不重复叠绘；其余882项原始要素不变。旧审计中的167米是校准前对照差，不代表当前误差。当前配准方法、约942米门址参照间距与文献1040米进深的未决差别、分期和精度限制详见 docs/luoyang-layout-calibration.md 与 .json；仍不作为实测复原成果。

随后发现上述门址两点旋转仍使南、东墙方向不一致，已撤销该方案。当前改为以定鼎门片区OSM现状长墙段核对南墙方向，复原影像四城角约束到同一开放外郭参考框架，宫区按考古图对应墙线匹配。原始几何与OSM构件不动，外郭校正副本仍开放；详情见 docs/luoyang-wall-constrained-calibration.md 与 .json。不得把现状短墙段约5米的一致性核对值当作全城考古定位精度。

南北向进一步以天街址标绘中线核对：固定南墙方向，只微调纵向基向量约0.368°；较长天街构件留作方向核对。112个坊市改用同一斜坐标格网，去掉四点投影带入的纵列倾斜，原始天街标绘不动。此为布局图示修正，不认定全部历史坊墙严格平行。

### 用户示意图参考版水系

按用户图补全洛水三股水道、两处主要洲岛、水面轻填充、6处历史桥线和西侧入洛水道；桥名仍核对考古报告图十，不照抄附件倒置的星津/黄道桥南北名称。新增10项，研究要素总计1021；仅更新原洛水粗岸线，其余1010项原有要素不动。详见 docs/luoyang-river-bridges.md 与 .json。原始图的出版来源、分期与精度未核，不因图面清楚而覆盖考古城墙、天街等定位。
