# 吴哥城矢量与考古图参照

`osm.geojson` 使用 OpenStreetMap 现状矢量，保留原始坐标、多多边形和孔洞；范围为吴哥城及护城河。121 个对象分为城墙／城门、寺庙／宫殿、平台、水系。导入记录见 `docs/angkor-osm-import.json`。每个对象保留 OSM 标识、原名、中文名、来源链接及 ODbL 署名。不能将现状几何理解为某个历史时期完整复原。

`efeo.geojson` 使用 EFEO 档案 FCA/2/DG/2756《Angkor Thom - carte archéologique》，补充王宫西侧围区、本特拉池和班通池的旧图范围，使用虚线及低透明填充。公开图像只有 480×480 像素，采用四个城角的统一尺度旋转配准；这些轮廓只是近似历史参照，不能作为精确考古测绘。配准参数、控制点、残差和逐项描绘像素保存在 `docs/angkor-efeo-georeferencing.json`。

EFEO 来源：https://archives.efeo.fr/index.php/fca-2-dg-2756 ，档案网站注明 CC BY-NC-SA 4.0；EFEO 派生数据保留此许可，与 OSM 数据分别标明来源和许可。地图弹窗提供逐项链接。

`surroundings.geojson` 新增23处吴哥周边主要景点，包括吴哥寺（小吴哥）、女王宫、崩密列、神牛寺、巴孔寺、罗洛寺、圣剑寺、塔布隆寺、斑黛喀蒂寺、龙蟠水池、塔逊寺、比粒寺、东梅奔寺、茶胶寺、托玛侬寺、周萨神庙、塔内寺、豆蔻寺、班蒂色玛寺、巴肯寺、皇家浴池、塔布隆小寺与克罗尔哥寺。采用OSM原始闭合几何，关系面保留孔洞，不同时导入整组关系及其成员造成重复。逐对象资料、原始几何及中文名称见 `docs/angkor-surroundings-import.json`。

吴哥仅作为地图古都专题，不写入中国古都列表。使用既有“古都”开关与朝代筛选，没有独立开关或图例。朝代是按年代对应的筛选分组，实际历史名称为高棉帝国吴哥时期：9世纪末对应隋唐；10世纪中叶对应五代十国；967年及12世纪主体对应宋辽金西夏。吴哥城的城圈对应12世纪末以后，图标兼作吴哥地区古都参照。详情明确各遗迹年代和性质，未知构件不擅自确定精确始建年。
