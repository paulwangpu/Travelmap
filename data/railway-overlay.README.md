# Railway overlay

The optional railway overlay uses the public OpenRailwayMap standard raster
tiles in the browser:

`https://tiles.openrailwaymap.org/standard/{z}/{x}/{y}.png`

The overlay is disabled by default and is intended for this public,
non-commercial map. It is not bulk-downloaded or redistributed by this
repository. The UI provides attribution to OpenRailwayMap and OpenStreetMap
contributors.

Data is derived from OpenStreetMap and is available under ODbL 1.0. Hosted
tile use is subject to the OpenRailwayMap usage policy.
