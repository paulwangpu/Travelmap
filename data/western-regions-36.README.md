# 西域三十六国补充

名单采用周振鹤《西汉政区地理》（人民出版社，1987，第179页）的36国考订口径，见[名单研究史](https://zh.wikipedia.org/wiki/西域三十六国)。汉书没有直接给出唯一36国名单，不把乌孙、大宛等其他版本国家拼进同一清单凑数。

`western-regions-36.json`保存36条人工核对的条目、资料链接及定位状态；`western-regions.js`只在加载时补充原古都目录，不覆盖原文件或修改用户打卡键。

- 4国复用原条目：龟兹、于阗、焉耆、疏勒，保留原坐标、名称、记录和siteKey。
- 16国增加地图参照点，其中13个为今地名的粗略示意点，按约两位小数表示，不是古都确址。3个为尼雅、交河、卓尔库特遗址的公开坐标，仍区分遗址坐标与历史身份认定。
- 原16国待考条目现按用户要求采用候选位置，统一标为 `inferred`（推测位置）：扜弥、渠勒、婼羌、小宛、戎卢、乌秅、西夜、子合、依耐、无雷、渠犁、车师后国、卑陆后国、蒲类后国、西且弥、东且弥。扜弥采用圆沙古城候选遗址坐标；其余是文献地望择一后的人工区域示意点，保留一位小数，不是自动地理编码结果，也不是都城考古确址。婼羌为活动区域而非固定都城。
- 合计古都清单328条记录、178个地图地点。西域36国均有参照点，其中16国为推测位置。32条新增记录；4条原记录只标注名单归属，不重复计数。

大致地望参照[西汉时期西域诸国列表](https://zh.wikipedia.org/wiki/西漢時期西域諸國列表)。原始王治记载参照[汉书卷96](https://www.chinese-classics.org/read/history/han-shu/han-shu-096)，不据古代里程反推精确坐标。

特别区分鄯善（楼兰更名）与现代鄯善县、温宿国与现代温宿县、尉犁国与现代尉犁县、无雷与乌垒。乌垒采用卓尔库特古城候选，不声称已无争议确证。蒲犁采用塔什库尔干参照点，不将现存石头城全部定为汉代。

公开遗址坐标参考Wikipedia条目（文件内coordinateUrl）；地望与考古关联优先国家博物馆、若羌县政府、社科网及大学考古研究。各条的note、sources在详情中显示。资料是编写者汇总和地图示意，不是精确考古测绘数据；Wikipedia引用资料遵循其CC BY-SA 4.0来源署名。

无雷择伊西洱库尔以东的帕米尔地望说；依耐择英吉沙／阿克陶一说，均保留其他说法。区域点仅表达当前选用假说的粗略位置，不能据此认定遗址或行政归属；每条note解释选址范围与限制。

运行 `node tests/western-regions.cjs` 验证完整名单、不重复、原目录身份保持、16个推测点及警示、加载失败回退及中英文标签。
