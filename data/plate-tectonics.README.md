# Global plate tectonics overlay

`plate-tectonics.geojson` contains 159 present-day line features extracted from
the EarthByte/GPlates Müller et al. 2019 global topology model. It includes
subduction zones, mid-ocean ridges, transforms, continental rifts, fracture
zones, faults, terrane boundaries, orogenic belts and inferred boundaries.

Model source:
https://www.earthbyte.org/webdav/ftp/gplately/Muller2019/Topologies.zip

The EarthByte data collection is distributed under Creative Commons
Attribution 3.0. The web app keeps the derived GeoJSON locally so the overlay
does not depend on a remote map service at runtime.
