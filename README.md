## 研究与数据接入记录

以下保留各阶段接入记录；当前数量、显示规则和移除项以发布说明及对应核验报告为准。

加德满都谷地补充：加德满都、帕坦、巴德岗三处历史中心采用古都图标及朝代控制；接入40个OSM建筑、庭院、石泉和广场对象，原始轮廓及孔洞保留。三处属于加德满都谷地世界遗产的组成区，不新增三个独立世界遗产。现状广场不是完整古城城界；明清等颜色仅为年代对照。来源与局限见 docs/kathmandu-valley-supplement.json。

世界古都补充：马六甲、顺化、升龙、开城、庆州、公州、扶余、汉阳、京都、奈良、特奥蒂瓦坎、特诺奇蒂特兰、帕伦克、奇琴伊察、库斯科、昌昌及马丘比丘，共17处主条目、139个OSM细节对象；平壤沿用原有条目。马丘比丘标为皇家城址而非帝国首都，景福宫不冒充昌德宫世界遗产。现代复建、现状范围和原始遗迹分别说明；接入资料见 docs/world-capitals-supplement.json。

日本古都完善：奈良补充东大寺、兴福寺、药师寺、唐招提寺、元兴寺、春日大社与UNESCO七个组成区代表点（八处资产）；新增镰仓、江户、飞鸟、藤原京、长冈京、难波京、首里，京都补充二条城。江户、二条城、首里添加公开现存石垣线；宫址与城市范围不混同。相关16项世界遗产定位审查与6项浏览代表点调整见 docs/related-heritage-location-review.json，原代表坐标保留。

平城京全城规划范围：依据奈良文化财研究所2025年图1条坊外缘，包含北侧边缘街坊及外京；七处图上地标／寺域近似中心仿射配准，拟合残差约71–139米（RMS约99米），非实测城墙或保护界。控制点不是测量基准点，不能将拟合残差当作全城定位精度。虚线、淡填充，由城墙范围隋唐控制；奈良古都详情提供全城定位按钮。见 docs/nara-heijo-kyo-plan.json。

平城京内部规划补充：21段主要街道图示线、朱雀大路及66个条坊格网单元，按奈文研北起条次、朱雀大路东西坊次规则标注；宫城、寺院、市场等占用区域保守省略。放大至13级显示线与规划分区、15级显示横向坊名；不当作实测坊墙、道路宽度或院落边界。见 docs/nara-plan-details.json。
